🧪 Postman API Flow (Admin Auth Module)
1️⃣ Register Admin
Method: POST

URL: http://localhost:8080/auth/register

Headers:

Content-Type: application/json

Body:

json
{
  "name": "Admin",
  "email": "admin@test.com",
  "mobile": "9876543210",
  "password": "Admin@123",
  "confirmPassword": "Admin@123",
  "role": "ADMIN"
}

------------------------------------------------------
2️⃣ Login Admin
Method: POST

URL: http://localhost:8080/auth/login

Headers:

Content-Type: application/json

Body:

json
{
  "email": "admin@test.com",
  "password": "Admin@123"
}
👉 Response मध्ये JWT मिळेल (data field).
-----------------------------------------------------------------------------
3️⃣ Register User (Admin JWT required)
Method: POST

URL: http://localhost:8080/auth/register

Headers:

Content-Type: application/json

Authorization: Bearer <Admin_JWT>

Body:

json
{
  "name": "Jayesh",
  "email": "jayesh@test.com",
  "mobile": "9876543211",
  "password": "Password@123",
  "confirmPassword": "Password@123",
  "role": "USER"
}
👉 Expected: 201 User registered successfully
